# Telecom-Customer-Churn-KPI-Analysis

## Project Overview

Developed an interactive Power BI dashboard for WE Telecom to monitor business performance, customer activity, and operational KPIs.

## Objectives

* Track revenue trends over time
* Analyze customer distribution
* Measure service performance
* Identify top-performing segments
* Improve decision-making through visual insights

## Tools Used

* Power BI
* Power Query
* Data Cleaning
* Data Modeling
* DAX
* Data Visualization

## Dashboard Features

* Revenue Overview
* Customer Insights
* Monthly Performance Trends
* Regional Analysis
* KPI Cards

## Key KPIs

* Total Revenue
* Active Customers
* Growth Rate
* Customer Retention
* Average Revenue per User (ARPU)
